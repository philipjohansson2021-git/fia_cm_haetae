## JKIISC 참고 사항

현재 `main.tex`는 두 번째 참고 논문에서 확인한 다음 특성을 일반 LaTeX
환경에서 재현한 초안이다.

- 학회지와 유사한 B5 계열 판형 및 2단 편집
- 첫 페이지를 제목·저자·요약 전용으로 사용하고 본문은 2페이지부터 시작
- 국문 제목과 영문 제목 병기
- 첫 페이지 전폭 국문 요약과 영문 Keywords
- 로마숫자 장 번호와 십진식 절 번호
- `Table 1.`, `Fig. 1.` 형식의 영문 캡션
- 서론 안에 별도 `Contributions` 항목 배치
- 각 장 도입부에서 해당 장의 목적과 전개 순서 설명
- 결과표를 본문에서 직접 인용하고 의미를 해설하는 문체
- 관련 연구, 제안 분석, 실험 결과, 결론의 빠른 전개
- 개요 그림으로 연구 대상과 오류 효과를 먼저 시각화
- 결론에서 핵심 수치, 종합 판단, 한계 및 향후 연구 순으로 정리

학회가 제공하는 공식 LaTeX 클래스나 템플릿을 확보하면 `main.tex`의
문서 클래스와 여백 설정을 공식 양식으로 교체해야 한다. 절별 본문은

## 작성 원칙

1. 기존 `paper/2026-07-29`의 문장과 구조를 그대로 복사하지 않음
2. 기존 자료는 실험 수치, 수식, 선행연구 및 한계 확인에만 사용
3. 대응기법보다 공격 가능성과 구현 의존성을 중심으로 서술
4. 소프트웨어 의미론적 오류와 실제 물리 글리치를 구분
5. 내부 응답과 직렬화 서명, `s1`과 전체 비밀키를 구분
6. RB는 직접 키복구가 아닌 잠재적 분포 누설로 제한
7. 대응기법은 보안 요구사항과 향후 연구 방향으로만 제시
8. T1을 핵심 물리 실험으로 두고 나머지 지점은 SW 취약성 분석으로 평가
9. T1의 최소 악용 출력 수와 전체 탐색·보정 비용을 분리하여 보고
