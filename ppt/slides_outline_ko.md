# 슬라이드 구성안 — HAETAE FIA & IRV (발표용 12장)

각 슬라이드: **제목 / 핵심 한 줄 / 넣을 내용(수식·표·코드) / 말할 포인트**.
상세 근거·값은 [`explainer_ko.md`](explainer_ko.md) 참조. 발표 시간 ≈ 10–12분 기준.

---

**S1. 제목**
- HAETAE에 대한 오류주입공격과 감염형 무작위 검증 대응기법(IRV)
- 부제: 서명 한 번 오류 → 비밀키 유출, 그리고 이를 막는 무분기 감염형 방어
- (발표자/소속/날짜)

**S2. 배경 — HAETAE와 오류주입공격(FIA)**
- 핵심 한 줄: "수학적으로 안전해도 **구현**은 오류주입으로 뚫릴 수 있다."
- 내용: HAETAE = KpqC 격자 서명(Fiat–Shamir with aborts). FIA = 클럭/전압 글리치로 연산을 교란.
- 포인트: 단 한 번의 오류로 전체 안전성이 무너질 수 있음.

**S3. 급소 — 비밀키를 쓰는 유일한 연산**
- 핵심 한 줄: "모든 위험은 이 한 줄에 있다."
- 수식: `z1 = y1 + (-1)^b · LN · (c·s1)`  (y=마스크, c=공개, s1=비밀, LN=8192)
- 포인트: 정상엔 `y`가 `s1`을 가림 → 이 줄의 곱(`c·s`)·덧셈(`+y`)이 표적.

**S4. 공격 지점 3종 (T1/T2/RB)**
- 표: T1(c·s 스킵→z≈y, 난수노출) / **T2(+y 스킵→z=c·s1, 비밀직접·가장 치명)** / RB(거부 스킵→큰 z 누설)
- 포인트: T2가 헤드라인. 다음 장에서 실제 숫자로.

**S5. T2 공격이 통하는 이유 — 실제 값 (임팩트 슬라이드)**
- 표: 정상 `z=100+8192·7=57444` vs T2 `z=8192·7=57344`
- 큰 글씨: **`57344 ÷ 8192 = 7 = c·s1`** → `c` 공개 → `ŝ1=NTT(z/LN)·ĉ⁻¹`
- 포인트: **서명 1개, 768계수 100% 복원.** 비결 = T2의 z는 LN의 정확한 배수(무손실).

**S6. IRV 아이디어 — "버리지 말고 감염시켜라"**
- 대비: 기존 = "검사해서 다르면 **버린다(if)**" / IRV = "오류 흔적 δ를 모아 **분기 없이 감염**"
- 그림 흐름: [응답 z] → [재계산·비교·노름재검사 → δ] → [δ=0? 그대로 : δ≠0? 난수화]
- 포인트: 버리는 if가 없다 → 그 if를 건너뛰는 2차 오류가 성립 불가.

**S7. IRV가 T2를 잡는 법 — 실제 값 (M4)**
- 핵심: 오류는 **출력**의 y를 지웠지만 `y1`은 **메모리에 그대로** → 재계산하면 정상값 복원.
- 표: 무결함 `107 vs 107 → 0` / T2 `방출 7 vs 재계산 107 → 7^107=108≠0`
- 포인트: 잔차 δ≠0 → 다음 장 마스크로.

**S8. 무분기 마스크 — if 없는 한 줄 (핵심 트릭)**
- 코드: `factor = 0u - (uint8_t)((δ|(-δ))>>63);  sig ^= ks & factor;`  (ks=SHAKE(비밀시드‖δ‖μ))
- 표: δ=0 → factor=0x00 → 그대로 / δ≠0 → factor=0xFF → 서명 전체 난수화
- 포인트: "0인가?"를 **분기 없이** 전0/전1 마스크로. 오탐 0, 결함 시 무효화.

**S9. RB와 두 경계(B1<B2) — 헷갈리는 지점 정리**
- 표: B1(서명경계 9839, 비밀보호·빡빡) vs B2(검증경계 12777, 위조방지·느슨)
- 그림: 수직선에 `0 —[B1 9839]— 틈 —[B2 12777]—`; RB는 틈에 z를 흘림
- 포인트: 서명후검증(B2)은 통과시켜 못 잡음 → **IRV는 B1으로 다시 봐서 잡음.**
- (비유: 공장검사 ±0.1mm 끄면 0.3mm가 출하검사 ±0.5mm 통과)

**S10. 2차 오류 — 기존 방어가 뚫리는 이유**
- 코드: `if (mism) memset(sig,0xFF)` (double) / `if (bad) memset(sig,0xFF)` (leeha)
- 포인트: **이 `if` 한 줄을 2차 오류로 건너뛰면** 누설 서명 그대로 방출. IRV엔 버릴 if가 없음 → 생존.

**S11. 비교 표 (결과)**
- 표: 커버리지(0/7·7/7·6/7·7/7) · RB(✗·✓·✗·✓) · 2차오류(—·우회·우회·**생존**) · 비용(1.0·2.0·1.14·**1.14**)
- 포인트: IRV = 7/7 + RB + 2차내성 + 이중연산 **절반 비용**. (코드/RAM은 트레이드오프.)

**S12. 마무리 — 한 줄 메시지**
- "오류를 **탐지-후-중단**하지 말고 **감염-후-무효화**하라. 버릴 if가 없으면 2차 오류도 없다."
- 30초 대본(explainer §7) 그대로 읽어도 됨.

## 부록 슬라이드(선택)
- **A1. 물리 실증(축 A)**: 실HW 클럭글리치로 T1 완전복원 768/768 — 단, 정직성 3조건(인과대조 빌드·고정 nonce·참키 대조). "실현성 연구"로 프레이밍. (`test/2026-07-18`, `2026-07-19`)
- **A2. 공개키 독립검증(W2)**: 복원 s1을 참키 없이 공개키만으로 확인(`verify_s1_pubkey`) — 오라클 의존 반박 제거.
- **A3. 실험 환경**: STM32F405 + CW308 + ChipWhisperer-Husky, HSE 7.37MHz, 결정론 DRBG.
