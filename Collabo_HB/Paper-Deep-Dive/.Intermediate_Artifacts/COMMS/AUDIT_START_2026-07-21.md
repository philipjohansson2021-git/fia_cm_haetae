- NuriMedia 2단 조판으로 좌·우단 문장 섞임, 수식 글리프 깨짐이 이미 관측됨.

### 3.3 [M] Canonical 동기화가 “규약”이지 “자동화”는 아님

- rsync를 턴마다 사람이(에이전트가) 기억해야 함.
- 한 번 빼먹으면 다시 “폴더에 안 보임” 재발.
- **권고(선택 구현):**  
  - 가능하면 **Canonical 경로에 직접 write**  
  - 또는 턴 종료 체크리스트를 `COMMS/LATEST.md` 하단에 고정 문구로 남김  
  - (원하면) 소형 sync 스크립트를 레포에 추가 — 현재 미구현

### 3.4 [M] 이중 경로(worktree / main) 잔존

- AI 실행 cwd가 worktree일 수 있음.
- 규약은 “메인 정식”이나, 실무상 write→sync 2단계.
- **권고:** 중요 파일은 메인 절대경로로 기록하는 습관을 기본으로 문서화(이미 §1.1-5). 본 검수 보고서는 **메인에 직접 기록**.
