# HAETAE 감염형 대응기법 논의 정리

> 작성: 2026-07-27 · 대상: `fia_cm_haetae` (HAETAE-IRV) · 상태: **개념·산술 검증 완료 / C 통합·실측·HW 검증 전**

---

## 0. 한 줄 결론

> **"싼 중복 검사 + 상쇄형 출력 마스킹"은 HAETAE에 적용 가능하다.** 단 2013 RSA의 *곱셈 융합*과 *모듈러스 확장*은 이식 불가이며, 페르마 정리의 다항식 대응물은 **비밀 평가점 태그**(`mod (x−α)`)다. 실측 결과 평가점 태그는 전체 재계산보다 **3.1× 저렴**하고, 비적응 결함에 대해 **1/q** 건전성을 갖는다. 반면 **적응적 오류 설계에는 취약**(2⁻⁸ ~ 최악 255/256)하므로 위협모델을 명시해야 한다.

---

## 1. 원 컨셉 확인 — 2013 RSA-Fermat (Seo et al., JKIISC 23(5))

원문 Algorithm 1 정독 결과, 실제 구조는 다음 4요소다.

| 요소 | 내용 |
|---|---|
| **중복성 운반체** | 모듈러스 확장 `N' = N·r` (r = 작은 소수, ~64비트) |
| **지수 분할** | `d = d' + d₁`, `d₁ = d mod (r−1)` → **주 지수승 1회 + k비트 보조 지수승 1회** |
| **검출(페르마)** | `m mod r`(입력측)로 `S mod r`(출력측)을 **싸게 예측** |
| **반응** | `S = (S₁·S₂) ⊕ T₁ ⊕ T₂` — 정상이면 `T₁=T₂`라 **상쇄**, 비교·중단 없음 |
| **비용** | ≈ 3k/n → n=1024, k=64에서 **18.79%** |

### 중요한 정정 두 가지

1. **2013도 "출력 마스킹"이다.** 단계 7–8에서 마스크를 최종 서명값에 XOR한다. §III의 "오류가 서명문 전체에 확산"은 산술 내부 확산이 아니라 **마스크 XOR로 인한 확산**이다.
   → **IRV의 post-encode 마스킹은 컨셉 이탈이 아니다.** `test/2026-07-25`의 "IRV는 원 컨셉의 절반" 자책은 이 지점에서 **과도한 자기비판**이었다.

2. **"비교 연산 없음"(§I)은 "검사 없음"이 아니다.** 2013도 `m mod r` ↔ `S mod r`라는 명백한 검사 채널을 갖는다. 다만 그 결과를 `if`로 판정하지 않고 **상쇄**로 처리한다.
   → "순수 내재형(중복성 없는 자동 확산) 불가능" 결론은 **원 논문도 하지 않는 것**을 대상으로 한 것이었다. 답 자체는 맞으나 목표를 막지 않는다.

## 2. HAETAE 이식 — 되는 것과 안 되는 것

2013은 두 가지 확산 기제를 갖는다.

| 기제 | 이식 | 이유 |
|---|:--:|---|
| **(a) 곱셈 융합** `S₁·S₂` (한쪽 오류가 곱으로 랜덤화) | ❌ | `z = y + LN·(−1)^b·c·s1`은 **아핀** — cs 오류가 z를 랜덤화하지 않고 *누설*시킨다 |
| **(b) 마스크 상쇄** `T₁ ⊕ T₂` | ✅ | 출력 바이트 레벨이라 rejection·인코딩과 무충돌 |
| **(c) 모듈러스 확장** `N·r` | ❌ | NTT는 2N차 단위근을 갖는 **소수** 필요 → `q·q'`는 CRT 분할이 강제되고, 그러면 **두 채널이 직교**해 q 채널 오류가 q' 채널에 나타나지 않음 (= `test/2026-07-25` A1이 dead였던 정확한 이유) |

**결론:** (a)(c)를 못 쓰는 대신 (b)를 구동할 **값싼 검사 관계**를 명시적으로 하나 만들면 된다. 이식의 전부가 이것이다.

## 3. 페르마 → 평가점 (핵심 매핑)

2013의 `mod r`은 **작은 몫환으로 내려보내 연산을 싸게 만드는 장치**다. 다항식의 대응물은 **비밀 평가점에서의 평가**(`mod (x−α)`)다.

| | 정수 (2013) | 다항식 (HAETAE) |
|---|---|---|
| 몫환 | `mod r` | `mod (x−α)` |
| 축소 효과 | 지수가 `mod (r−1)` (페르마) | 다항식 곱 → **스칼라 곱** |
| 값싼 예측 | `S mod r` ← `m mod r` | `(c·s)(α) = c(α)·s(α)` |

성립 조건: **`α^256 ≡ −1 (mod q)`**. `q−1 = 64512 = 2¹⁰×63`이라 `512 | q−1` → 원시 512차 근이 존재하므로 negacyclic 감산이 자동 처리되어 항등식이 **정확히** 성립한다.

## 5. 제안 설계 — FTC (Fermat-style Tag Cancellation)

```
1. 주 연산 1회        : 레퍼런스 c·s (NTT 경로) — 손대지 않음
2. 값싼 중복 채널     : 비밀·신선한 평가점 α₁..α_t  (α^256 ≡ −1, 서명·시도·블록마다 파생)
   예측(입력측) τ_E,i = c(α_i) · s1(α_i)      ← Horner 2회   ← 페르마 역할
   관측(출력측) τ_O,i = (c·s1)(α_i)           ← Horner 1회
3. transcript 확장    : +y 관계(T2), reject 상태(RB)를 같은 transcript에 추가
4. 반응(비교·중단 없음):
   Θ_E = enc(τ_E‖ζ_E‖0,0‖ctx),  Θ_O = enc(τ_O‖ζ_O‖r1,r2‖ctx)
   σ* = σ ⊕ SHAKE256(K‖Θ_E) ⊕ SHAKE256(K‖Θ_O)
        정상: Θ_E=Θ_O → 상쇄 → σ* = σ (bit-exact, 오탐 0)
        오류: Θ_E≠Θ_O → 두 스트림 독립 → 서명 난수화
```

**독립성 필수 조건** (공통모드 결함 방지)
- 예측 태그는 **coefficient-domain `c`와 별도 `s1` 사본**으로 계산 (주 경로의 `chat`·NTT-domain `s1`·`cs1` 사용 금지)
- 관측 태그는 `polyvecl_cneg` **이후**의 실제 `cs1`에서 계산 (부호 오류까지 포착)
- 마스크는 반드시 **keyed XOF**(`SHAKE256(sk_seed‖ctx‖Θ)`). 2013의 "작은 잉여값 ⌈n/k⌉회 반복" 마스크는 구조가 출력에 남아 현대 기준 부적합

## 6. 정직한 한계 3가지 (논문에 반드시 명시)

1. **적응적 오류 설계에 약하다 (실측 확인).** 유효 α가 256개뿐이므로 공격자가 오류 다항식에 근을 심으면 2⁻⁸, 최악의 경우 255/256까지 미탐. **단** 측정된 물리 결함(clean-skip / zeroing / bitflip / garble)은 255개 근을 갖는 오류 다항식을 만들 수 없다 → **"측정된 결함모델 하에서 1/q"로 범위를 한정**하거나, 강한 주장이 필요하면 균일 ρ(비용 2.9×)를 쓰는 트레이드오프.
   - 참고: **2013도 확률적**이다(r-잉여 우연 일치 ≈2⁻⁶⁴). "확률적 검출"은 컨셉 이탈이 아니다.
2. **α(또는 ρ)가 새로운 단일 실패점.** 0으로 만들면 `τ_E=τ_O=0`이라 검출기가 침묵한다. "XOF squeeze 스킵 → 버퍼 0"은 축 B에서 **재현율 100%인 가장 쉬운 결함(SEED-class)** → 파생 경로 하드닝 필수(0 불가 구조, 경로 분리).
3. **무결함에도 PRF 2회.** 서명 길이(1,474 B) SHAKE256을 항상 두 번 짜낸다(IRV는 1회). ≈+11 Keccak 순열이므로 태그로 절약한 것을 상당 부분 상쇄 → 비용표에 반드시 계상.

## 8. 이전 논의 연결 (배경)

- **IRV 코드-논문 갭** (`test/2026-07-25` 지적, 코드로 확인): `haetae_sign_cm.c`의 δ 누적은 실제로 `if(...) cm_delta |= 1` — **1비트 + 데이터의존 분기**이고 무분기는 최종 `factor`뿐. 논문의 "wide·무분기·2⁻ʷ" 주장과 불일치. → `|= (a^b)` wide-δ(CM_IRI, PASS 16/0) 또는 본 문서의 **상쇄 구조**가 근본 해결.
- **Lee-Ha 관계**: 커버리지는 **보완**(IRV 단독 x86 21.3%, 응답무결성 class만 100% / Lee-Ha 97.9%·RB 0%), 아키텍처는 **극복**(detect-and-abort → 무분기 감염). 최선의 서술은 *"임의의 탐지를 2차내성 감염형으로 끌어올리는 일반 변환, Lee-Ha는 그 인스턴스·기준선"*.
- **물리 공격 모델**: 레드팀 13경로 전부 현행 IRV에 미성립(융합 클린-스킵 물리 불가 + M1 별도시간창 재계산 + 무분기 감염 + M1′ 외부검증 + production은 `T1_CS_ZEROINIT` 미포함). 잔존 = **A3(M1의 z1 전용 커버리지 갭, 확정 코드 사실)** · A2(RB) · Model-X(δ/감염 라인 직접 타격). *단 IRV에 실제 글리치를 쏜 실험은 아직 없음.*
- **미해결 리서치 갭**: PCM-DFA(챌린지 샘플링 loop-abort)는 Lee-Ha도 IRV도 미방어 — IRV의 M1은 *방출된 같은 c*로 재계산하므로 미탐. `HW(c)=τ` 검사 부재.
